Repository `https://github.com/wolf109909/zinwa-q25-linux` (local `/home/maxsun/zinwa-q25`) contains:
- `drivers/`: All 11 Zinwa Q25 (`q20_v12_factory` / MediaTek Helio G99 `MT6789`) hardware kernel modules (`bbqX0kbd.ko`, `q20_keyboard.ko`, `synaptics_dsx_q25.ko`, `ocp2131_drv.ko`, `panel-q20-hd720-lcm-dsi-vdo.ko`, `upm6922_charger.ko`, `upm6722.ko`, `snd-soc-oca72xxx.ko`, `st21nfc.ko`, `aw36518.ko`, `flashlight-gpio-v4l2.ko`) forward-ported from vendor 5.10 to compile cleanly with 0 warnings against Mainline Linux 7.0 (`ellyq/mtk_g99-mainline`) via Kbuild or `drivers/dkms.conf`.
- `devicetree/mt8781-zinwa-q25.dts`: Complete Mainline Linux 7.0 DeviceTree wiring up Q25 keyboard (`&i2c6 @ 0x1f` + `pdrv_bbqX0kbd`), touchscreen (`&i2c0 @ 0x67`), display panel (`&dsi0` + `&i2c7 @ 0x3e`), chargers (`&i2c5 @ 0x6b` & `0x65`), audio PA (`&i2c3 @ 0x58`), NFC (`&i2c3 @ 0x08`), RGB LEDs, keys, and Panfrost Mali-G57 GPU.
- `cachyos/`: `PKGBUILD`, `cachyos-mt6789.config`, and `config-mt6789-mainline-7.0.aarch64` for `linux-cachyos-q25` + `zinwa-q25-dkms`.
- `userspace/`: `keyd` config, `arch`/`arch-mount`/`arch-env.service`, Wayland GUI wrappers (`rustdesk`, `firefox`, `arch-sync-desktop`), and Q25 CLI helpers (`bright`, `q25-status`, `q25-hotspot`).
