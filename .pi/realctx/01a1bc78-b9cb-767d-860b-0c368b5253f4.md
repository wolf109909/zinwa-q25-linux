On the flashed Q25 Arch image (pre-btrfs), user alarm (wheel) could not sudo: the image shipped no sudoers wheel rule. pkexec over ssh (even with -tt / pkttyagent) failed with `GDBus.Error:org.freedesktop.PolicyKit1.Error.Failed: No session for cookie`. Fix in repo: rootfs/etc/sudoers.d/10-wheel (`%wheel ALL=(ALL:ALL) ALL`, chmod 0440 in build-rootfs.sh). USB NCM usb0 was NM-unmanaged by stock 85-nm-unmanaged.rules (DEVTYPE=gadget) -> rootfs/etc/udev/rules.d/86-q25-usb-gadget.rules sets NM_UNMANAGED=0. ccci_mdinit looped 203/EXEC because ExecStartPre ran inside Android RootDirectory -> RootDirectoryStartOnly / drop sleep in q25-ccci@ccci_mdinit.service.d/order.conf. faillock: Arch default deny=3 unlock_time=600 locks PIN logins quickly; repo now ships deny=10 unlock_time=120. Evidence: docs/validation-hw.md.
