On Zinwa Q25 (`MT6789`, `7.3.3-cachyos-q25`) with Arch Linux ARM in `/opt/arch`:
- **Phosh 0.57.0 + Phoc 0.57.0 on 720x720 DSI-1**:
  - Arch's `phoc 0.57.0-2` links system `wlroots0.20` (`0.20.2`), which lacks phoc's `0001-Revert-layer-shell-error-on-0-dimension-without-anch` patch. Phosh's home/drag surface requests height 0 with only bottom/left/right anchors, causing `Error 71 (Protocol error)` and a `phosh.service` crash loop.
  - Use `packages/phoc-q25`, which builds phoc against embedded wlroots with that patch (provides/conflicts `phoc`). Build with `sudo env BUILDROOT=$HOME/q25-work/mm-buildroot ./build/build-packages.sh packages/phoc-q25` (~4 min). `build-rootfs` installs it with `pacman -U --ask 4`; on a live phone use `pacman -Rdd phoc && pacman -U phoc-q25-*.pkg.tar.xz` because plain `--noconfirm` refuses the conflict. Verified on-device: `NRestarts=0`, lock screen renders.
  - Pass `-U` (`--unlocked`) to `/usr/lib/phosh/phosh` so Phosh starts unlocked directly on the home screen.
  - Export `WLR_NO_HARDWARE_CURSORS=1` for `phoc` so `wlroots` composites the optical trackpad cursor onto `OVL_L0` instead of driving `OVL_L1` hardware cursor updates mid-scanout.
- **Kernel OVL/CRTC vblank synchronization (`drivers/gpu/drm/mediatek/{mtk_crtc.c,mtk_disp_ovl.c}`)**:
  - Because `DISP_OVL_BYPASS_SHADOW` (`BIT(22)`) is enabled without CMDQ, `mtk_crtc_update_config()` must only call `mtk_crtc_ddp_config(crtc, NULL)` synchronously when `!needs_vblank` (initial CRTC enable), and rely on `mtk_crtc_ddp_irq()` (`OVL_FME_CPL_INT` at 60 Hz) for all `needs_vblank` page flips.
  - In `mtk_ovl_layer_on()`, skip rewriting `DISP_REG_OVL_RDMA_CTRL(idx)`, `DISP_REG_OVL_RDMA_GMC(idx)`, and `DISP_REG_OVL_SRC_CON` when `!cmdq_pkt && (readl(ovl->regs + DISP_REG_OVL_SRC_CON) & BIT(idx))`.
- **Backlight (`pwm-backlight` on `1100e000.pwm`) & `q25-logind-shim`**:
  - In `drivers/display/panel-q20-hd720-lcm-dsi-vdo.c`, call `backlight_enable(ctx->backlight)` in `lcm_probe()` when `ctx->enabled = true` so `/sys/class/backlight/backlight/bl_power` starts at `0` (`FB_BLANK_UNBLANK`).
  - `/usr/local/sbin/q25-logind-shim` claims `org.freedesktop.login1` on the system D-Bus and implements `org.freedesktop.login1.Session.SetBrightness` on `/org/freedesktop/login1/session/auto` so Phosh Quick Settings can control `/sys/class/backlight/backlight/brightness` (`0..1023`).
