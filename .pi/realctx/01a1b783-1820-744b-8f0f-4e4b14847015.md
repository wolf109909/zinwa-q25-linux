On Zinwa Q25 (`MT6789` / `MOLY.LR13.R2.MP.V85.3`), 4G LTE (`ccmni0`) uses `ccci_hif_dpmaif_v1.c` with `tx_sw_solution_enable = 1` (`dpmaif_tx_send_skb_to_smem` over `SMEM_USER_MD_DATA` at `0x40910000`). Three bugs in `drivers/mediatek/eccci/hif/ccci_hif_dpmaif_v1.c` and `drivers/mediatek/ccmni/ccmni.c` caused MD1 to assert in `mcu/driver/dpcopro/src/lhif_dev_data.c:1675` or drop TCP/UDP packets:

1. **SMEM UL Non-linear SKB Crash (`lhif_dev_data.c:1675`)**:
   - The modem's SMEM UL firmware (`lhif_dev_data.c`) expects **1 MSG DRB + 1 contiguous PD DRB** per packet (`c_bit=0` on the single PD DRB).
   - Because `port_net.c` sets `MODEM_CAP_SGIO`, `ccmni_dev_init()` enabled `NETIF_F_SG`, so TCP/TLS sockets passed multi-fragment `skb`s (`skb_shinfo(skb)->nr_frags > 0`), causing `dpmaif_set_skb_data_to_smem_drb()` to emit PD DRBs with `c_bit=1` (`0x00340004`), which immediately crashed MD1 (`lhif_dev_data.c:1675`).
   - Fix: Call `if (skb_is_nonlinear(skb)) skb_linearize(skb);` and set `send_cnt = 2` in `dpmaif_handle_skb_data()`, and disable `NETIF_F_SG` in `ccmni_dev_init()`.

2. **CCMNI TX Queue Mapping (`ccmni->ack_prio_en`)**:
   - During boot, MD1 sends RPC `0x400A` (`ccci_rpc_remap_queue` in `port_rpc.c`) which sets `ccmni0` `txq_index = 0` (`Q0`) and `txq_exp_index = 0xF1` (`Q1`).
   - However, MD1 only polls SMEM UL `Q0` (`smem_drb_qinfo[0]->rd` advances, while `Q1` `rd` stays `0`). When `ccmni->ack_prio_en = 1`, `is_ack_skb()` routes TCP SYN/ACK packets to `Q1`, where MD1 never reads them.
   - Fix: Set `ccmni->ack_prio_en = 0` in `ccmni_inst_init()` so all `ccmni0` traffic uses `Q0`.

3. **DPMAIF v1 DL BAT Reallocation Order**:
   - In `dpmaif_get_rx_pkt()` (`!_97_REORDER_BAT_PAGE_TABLE_`), `dpmaif_alloc_rx_buf()` was called before `dpmaif_rx_set_data_to_skb()`, overwriting `cur_skb->skb` before reading the received packet, and calling `drv1_dpmaif_dl_add_frg_bat_cnt(0, 0)` when `notify_cnt->frag_cnt == 0`.
   - Fix: Read `dpmaif_rx_set_data_to_skb()` first, reallocate the BAT slot in `dpmaif_rx_start()` after `dpmaif_send_skb_to_net()`, and guard `notify_cnt->frag_cnt != 0` / `notify_cnt->bat_cnt != 0` in `dpmaifq_rx_notify_hw()`.
