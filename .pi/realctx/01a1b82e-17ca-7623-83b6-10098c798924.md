On Zinwa Q25 (`MT6789`, Mainline Linux `7.3.3-cachyos-q25`), `/vendor/bin/ccci_mdinit` calls Bionic's `__android_log_print` / `__android_log_buf_print` when `ccci_fsd(1)` finishes modem NVRAM/FS bootup (`md status event 10` -> `vendor.mtk.md1.status=ready`). If `libprop_preload.so` does not export `__android_log_print` and `__android_log_buf_print` (e.g., if an older `libprop_preload.so` without those symbols is still staged in `/tmp/libprop_preload.so`), Android's `liblog.so` fails trying to write to Android's logd socket and `ccci_mdinit` exits right after bootup (~15s after start), closing `/dev/ccci_monitor` and triggering `dev_char_close` -> `force_md_stop()` (`md1:4` -> `md1:7` -> `md1:1`). Ensure `/tmp/libprop_preload.so` exports `__android_log_print` and `__android_log_buf_print`. Also sync system UTC time on boot (MT6789 RTC defaults to 2033 if unset, which causes OpenSSL TLS certificate verification to fail with `certificate has expired`).
