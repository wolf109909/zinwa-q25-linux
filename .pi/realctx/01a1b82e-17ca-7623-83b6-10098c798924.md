On Zinwa Q25 (MT6789, Mainline Linux `7.3.3-cachyos-q25`):
- Always run `q25-modem-init` inside the `/opt/arch` chroot when `/opt/arch/usr` exists: `exec chroot /opt/arch /usr/local/sbin/q25-modem-init "$@"`.
- Launch `ccci_rpcd` before `ccci_mdinit` with `setsid ... </dev/null`, so it listens on `/dev/ccci_rpc` during MD1 Handshake 2 (`MD_BOOT_HS2`) and neither daemon gets `SIGHUP` when shells/TTYs close.
- Never overwrite `/apex/com.android.runtime/lib64/bionic/libc.so`, `/apex/com.android.runtime/bin/linker64`, `/system`, or `/tmp/libprop_preload.so` while `ccci_mdinit` or `ccci_rpcd` is running. In-place overwrite of `mmap`ped shared libraries triggers `SIGBUS`, closes `/dev/ccci_fs` and `/dev/ccci_monitor`, and makes kernel CCCI call `force_md_stop`.
- Ensure `/tmp/libprop_preload.so` exports `__android_log_print` and `__android_log_buf_print`. When `ccci_fsd(1)` finishes modem NVRAM/FS bootup (`md status event 10` -> `vendor.mtk.md1.status=ready`), `/vendor/bin/ccci_mdinit` calls these Bionic logging functions. If the symbols are missing, `liblog.so` fails writing to logd and `ccci_mdinit` exits about 15 seconds after start, closes `/dev/ccci_monitor`, and triggers `dev_char_close` -> `force_md_stop()` (`md1:4` -> `md1:7` -> `md1:1`).
- Include boolean `"data_enabled"`, boolean `"roaming"`, and `"apn"` in `q25-modem-init status` JSON; otherwise `q25-control-center` Stage 2 refresh can switch Mobile Data off after `data-up`.
- Sync system UTC time on boot: the MT6789 RTC defaults to 2033 if unset, causing OpenSSL TLS certificate verification to fail with `certificate has expired`.
