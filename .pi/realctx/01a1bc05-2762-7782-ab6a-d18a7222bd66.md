`aarch64-linux-gnu-gcc --sysroot=~/q25-work/rootfs` fails to link (`cannot find /lib/libc.so.6: file in wrong format`): the toolchain's own libc.so linker script is found first, and its absolute `/lib/...` paths are not prefixed with the sysroot. `build/build-rootfs.sh` stage_overlay therefore builds `q25-wmt-init` and `q25-bt-vhci` with `$CC -static -O2 -Wall`, which also avoids depending on the target glibc version. `libprop_preload.so` stays `-nostdlib -shared -fPIC`.
