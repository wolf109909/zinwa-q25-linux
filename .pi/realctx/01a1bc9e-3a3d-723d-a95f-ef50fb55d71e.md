On the native Arch image (stock ModemManager + modemmanager-q25 mtk-ccci plugin), the modem stays `registration: denied`/searching until an initial-EPS (attach) APN is configured; the plugin rejects an empty APN. `mmcli -m any --3gpp-set-initial-eps-bearer-settings="apn=ctnet,ip-type=ipv4"` registers immediately (China Telecom 46011). Working profile: `nmcli c add type gsm ifname '*' con-name mobile gsm.apn ctnet gsm.initial-eps-bearer-configure yes gsm.initial-eps-bearer-apn ctnet ipv6.method disabled connection.autoconnect yes` → ttyC0 gsm connected, ccmni0 /32 IPv4, default route metric 700, HTTPS OK (verified 2026-11). `build/build-rootfs.sh` ships this as `mobile.nmconnection` when `Q25_APN=<apn>` is set.
