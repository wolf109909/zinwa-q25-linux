On Zinwa Q25 (`MT6789`, Mainline Linux `7.3.3-cachyos-q25`), all hardware controls and desktop services run natively inside the `/opt/arch` Arch Linux ARM environment:
- **GUI Hardware Control Center (`/usr/local/bin/q25-control-center`, source in `userspace/bin/q25-control-center`):**
  - Built with Python 3 + GTK 4 + Libadwaita (`Adw.Application`), tailored for the `720x720` square DSI display in dark mode, with 3 tabs (`Alt+1` Controls, `Alt+2` Wireless, `Alt+3` System; `Ctrl+R` refresh).
  - **Controls tab:** Screen Backlight slider (`10..1023` -> `/sys/class/backlight/backlight/brightness`), Keyboard Backlight slider (`0..255` -> `/sys/class/leds/q25:white:kbd_backlight/brightness`), Audio Volume slider (`wpctl` PipeWire + ALSA `Lineout Volume` / `Headphone Volume`), Audio Output Route selector (`Speaker`, `Receiver`, `Headphone`, `Speaker+Headphone` -> ALSA `Q25 Output Route`), Optical Trackpad Mode toggle (`Cursor` vs `D-Pad` -> `/proc/Trackpad_Mode`), Rear Torch LED toggle (`/proc/q20_torch` / `GPIO 154`), and Haptic Vibration test (`/proc/q20_vibrator` / `MT6358 vibr`).
  - **Wireless tab:** 4G LTE Cellular Data switch (`ccmni0` via `q25-modem-init data-up`/`data-down`), Data Roaming switch (`AT+EROAMING` via `q25-modem-init roaming on|off`) + Carrier APN entry on a compact single row, Wi-Fi (`wlan0`) switch + SSID scanner + password connect via `NetworkManager` (`/etc/NetworkManager/conf.d/99-q25.conf` sets `wifi.scan-rand-mac-address=no` and leaves `usb0`/`ccmni*` unmanaged), and Bluetooth 5.4 (`hci0`) switch + BlueZ D-Bus device discovery.
  - **System tab:** Live Battery/Voltage/Current/Temperature/IP status, RGB Status LED toggles (`red`/`green`/`blue`), Kernel & BORE scheduler status, and `Foot` terminal launcher.
- **Session Startup (`/usr/local/sbin/q25-phosh-start`, source in `userspace/sbin/q25-phosh-start`):**
  - Mounts `/dev/shm`, corrects PMIC RTC year drift (e.g. `2086` -> `2026`), starts `systemd-udevd`, `dbus-daemon`, `seatd`, `upowerd`, `q25-wmt-init` + `q25-bt-vhci` + `bluetoothd`, `wpa_supplicant` + `NetworkManager`, `q25-modem-init start`, `pipewire` + `wireplumber` + `pipewire-pulse`, `q25-logind-shim`, `phoc` + `phosh`, `foot`, and `q25-control-center`.
