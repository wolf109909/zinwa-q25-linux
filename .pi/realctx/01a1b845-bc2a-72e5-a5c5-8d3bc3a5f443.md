For the Zinwa Q25 Arch distro, provide a standard Linux desktop optimized for the 720x720 touchscreen and hardware keyboard. Prefer upstream tools: a real terminal emulator (e.g. kitty), NetworkManager with nmtui or a normal GUI (GNOME Settings / nm-connection-editor), and standard BlueZ/PipeWire UIs. Do not build custom shell overlays, control-center/settings apps, or ad-hoc scripts for user-facing features. Integrate hardware through drivers, standard daemons, udev, and systemd so stock desktop tools work; cellular should use ModemManager/NetworkManager rather than a private CLI.
