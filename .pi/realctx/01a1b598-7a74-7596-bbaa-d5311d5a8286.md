User preference for Zinwa Q25 (`wolf109909/zinwa-q25-linux`):
- Drop all remnants of the old "Arch Linux inside 5.10 Droidian as a chroot/container" setup (`droidian-boot-5.10.247.img`, `droidian-lvm-q25-*.img.xz`, `userspace/bin/arch`, `userspace/sbin/arch-mount`, `userspace/systemd/arch-env.service`, `userspace/arch-chroot/arch-sync-desktop`, etc.).
- Everything must be based on the latest Mainline Linux kernel (`7.3.3-cachyos-q25`) and boot directly into a pure, native Arch Linux ARM base rootfs (`systemd` PID 1, native Wayland/Phosh/Mesa Panfrost Mali-G57 MC2, `keyd`, USB NCM SSH, etc.).
