## 1. Verified Working Hardware & Desktop Subsystems on 7.3.3-cachyos-q25
- **Native DRM/KMS/DSI Display (`mediatek-drm` `card2`)**:
  - Pipeline: `14000000.syscon` (`mmsys`) + `14001000.mutex` + `14005000.ovl` (`ovl0`) + `14007000.rdma` (`rdma0`) + `14013000.dsi` (`dsi0`) + `11f60000.mipi-tx` + `panel-q20-hd720-lcm-dsi-vdo.ko` + `ocp2131_drv.ko` (`7-003e`).
  - Active at `720x720@60Hz` (`card2-DSI-1` connected/enabled, `mediatekdrmfb` on `/dev/fb0`), hardware vblank IRQs firing at 60 Hz on `14005000.ovl`.
  - Fixed optical trackpad cursor flickering/duplication and bottom-row flashing by setting `WLR_NO_HARDWARE_CURSORS=1` in `phoc`, deferring `mtk_crtc_ddp_config(crtc, NULL)` to `mtk_crtc_ddp_irq()` when `needs_vblank` is true in `drivers/gpu/drm/mediatek/mtk_crtc.c`, and skipping redundant `DISP_REG_OVL_RDMA_CTRL`/`DISP_REG_OVL_SRC_CON` writes in `mtk_ovl_layer_on()` when `BIT(idx)` is already enabled.
- **PWM Backlight (`1100e000.pwm` + `pwm-backlight`)**:
  - `lcm_probe()` in `drivers/display/panel-q20-hd720-lcm-dsi-vdo.c` calls `backlight_enable(ctx->backlight)` so `/sys/class/backlight/backlight/bl_power` starts at `0` (`FB_BLANK_UNBLANK`, range `0..1023`).
  - `/opt/arch/usr/local/sbin/q25-logind-shim` (`userspace/sbin/q25-logind-shim`) claims `org.freedesktop.login1` on the system D-Bus and implements `org.freedesktop.login1.Session.SetBrightness` on `/org/freedesktop/login1/session/auto`.
- **3D GPU & DVFS (`panfrost` + `mediatek-regulator-coupler`)**:
  - Mali-G57 MC2 (`13000000.gpu`, `/dev/dri/card1`, `renderD128`) running Mesa `26.2.6-arch1.1` (OpenGL 3.1 / OpenGL ES 3.1) with `mt6366_vgpu_reg` ↔ `mt6366_vsram_gpu_reg` coupling across 36 OPPs (`390 MHz` – `1.1 GHz`).
- **Arch Linux ARM Wayland / Phosh Graphical Desktop (`/opt/arch`)**:
  - Auto-started on boot via `/opt/arch/usr/local/sbin/q25-phosh-start` (`userspace/sbin/q25-phosh-start`) invoked from `/init` (`userspace/sbin/init-7.3.3-cachyos-q25`).
  - Runs `dbus-daemon --system`, `seatd`, `upowerd`, `q25-logind-shim`, `phoc 0.57.0`, `phosh 0.57.0 -U` (unlocked), and `foot` terminal on `wayland-0` (`720x720`).
  - Uses `G_RESOURCE_OVERLAYS=/mobi/phosh/ui/home.ui=/etc/phosh/home.ui` (`userspace/arch-chroot/home.ui`) with `<property name="height">720</property>` on `PhoshHome` to avoid wlroots layer-shell protocol error 71 (`height 0 requested without setting top and bottom anchors`).
- **Input (`bbqX0kbd`, `q20_keyboard`, `keyd`, `synaptics_dsx_q25`, `mtk-pmic-keys`, `gpio-keys`)**:
  - Physical QWERTY keyboard + optical trackpad (`6-001f`) remapped by `keyd.rvaiya`, capacitive touchscreen (`0-0067` `s2716b_ts`), and hardware buttons all working in Wayland/Phosh.
- **Thermal Zones & Battery Fuel Gauge**:
  - 7 thermal zones (`/sys/class/thermal/thermal_zone0..6`): `soc-thermal`, `cpu-thermal`, `gpu-thermal`, `vcore-thermal`, `battery-thermal` (via `mt6359-auxadc` + `generic-adc-thermal`), `upm6922-charger`, and `battery`.
  - Full `/sys/class/power_supply/battery` metrics (`CAPACITY`, `VOLTAGE_NOW`, `CURRENT_NOW`, `TEMP`, `STATUS`, `HEALTH`) + `upm6922-charger` (`5-006b`) + `upm6722-standalone` (`5-0065`).
- **ALSA Audio & Smart PA (`ZinwaQ25Audio`)**:
  - Card 0 (`mt6358-sound` + `snd-soc-oca72xxx` `3-0058`) registered with `firmware/ocs72xxx_cf.bin` (extracted from vendor partition and embedded in initramfs `/lib/firmware/ocs72xxx_cf.bin`) loaded and parsed (`Music`, `Receiver`, `Off` profiles).
- **Storage, NFC, Flash/Torch, LEDs**:
  - 256 GB UFS (`ufshcd-mtk`, 224.2 GB LVM `/rootfs` + `/opt/arch`), `st21nfc` (`3-0008`), `aw36518`, `flashlight-gpio-v4l2`, and `leds-gpio` (`red`/`green`/`blue`).
