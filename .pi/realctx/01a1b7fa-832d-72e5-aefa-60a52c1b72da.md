On Zinwa Q25 (`MT6789`, Mainline Linux `7.3.3-cachyos-q25`), `drivers/keyboard/bbqX0kbd_main.c` (`bbqX0kbd.ko`) registers standard LED class devices and `/proc` nodes for all board peripheral controls:
- **Keyboard backlight**: `/sys/class/leds/q25:white:kbd_backlight/brightness` (`0-255`) and `/proc/q20_kbd_brightness` (`REG_BKL = 0x05` on I2C6 `0x1f`).
- **Torch / Flashlight**: `/sys/class/leds/q25:white:torch/brightness` (`0` = off, `1` = torch, `2` = high/flash) and `/proc/q20_torch` (resolves MT6789 pinctrl GPIOs `154` = enable and `155` = mode via `gpio_device_find_by_fwnode()` on `"mediatek,mt6789-pinctrl"`).
- **Vibrator / Haptics**: `/sys/class/leds/q25:vibrator/brightness` (`0`/`1`) and `/proc/q20_vibrator` (`0` = off, `1` = continuous on, `2..5000` = timed pulse in milliseconds using `regulator_get_optional(NULL, "vibr")` for the MT6358 `vibr` 2.8V LDO).
- **Trackpad key/mouse mode**: `/proc/q20_switch_key_mouse` (`0` = mouse mode, `1` = key mode).
